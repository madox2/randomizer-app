# Randomizer App

Ultimate randomizer mobile/web application created with [Expo](https://expo.dev), [react-native](https://reactnative.dev/) and [react-native-web](https://github.com/necolas/react-native-web).

<img src="doc/preview.png" alt="preview" width="320">

[![web](doc/available_web.png)](https://madox2.github.io/randomizer-app/)

[![android store](doc/available_android.png)](https://play.google.com/store/apps/details?id=com.randomizerapp)

## Features

* **Numbers**: get a random number in a range you choose
* **Coin**: flip the coin
* **Bottle**: spin the bottle
* **Magic 8-Ball**: ask a yes/no question
* **Matches**: pull a match, someone gets the burned one
* **Dices**: throw one or more dice with any number of sides
* **Cards**: draw from a shuffled 52-card deck, without putting cards back
* **Teams**: shuffle your players into a chosen number of teams, the list of players is saved
